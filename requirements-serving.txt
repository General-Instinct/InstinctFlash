# What a machine needs to SERVE a wan_va checkpoint through the InstinctFlash public API.
#
# Derived by building this environment from scratch on a clean 4x H100 box (2026-08-10) and running
# tools/lingbot_end_to_end.py until it passed. Every version here is the one that combination was
# verified with, not the newest that might work.
#
#   python3 -m venv ~/.venv-lingbot
#   ~/.venv-lingbot/bin/pip install -r requirements-serving.txt \
#       --extra-index-url https://download.pytorch.org/whl/cu126
#
# NOT installable from here, but required:
#   * the upstream lingbot-va checkout, at LINGBOT_ROOT or ~/.cache/instinctflash/lingbot-va
#
# A real flash-attn wheel is optional: without one, InstinctFlash adds its import-only `flash_attn`
# stub (instinctflash/runtime/_shims) to sys.path; this path runs attn_mode='torch' and never calls it.
#
# The weights are NOT a dependency. `Runtime.from_pretrained` fetches the package, and the frozen
# stack resolves from the checkpoint's own `execution.base_weights` pointer.
